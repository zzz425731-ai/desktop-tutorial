# 🧹 垃圾软件检查

一个 Windows 小工具：帮你找出电脑里常见的**捆绑软件、弹窗软件**，还有**早就停止更新的老软件**，并告诉你为什么建议卸载。

![垃圾软件检查截图](screenshot.png)

## 它会检查什么

- **已经安装的软件**：和控制面板里「程序和功能」看的是同一份登记（从微软应用商店装的应用不包括在内）
- **开机自动启动的程序**：注册表里登记的启动项，加上「启动」文件夹里的

## 两种提醒

| 标记 | 意思 | 例子 |
| --- | --- | --- |
| **建议卸载**（红色） | 常被捆绑安装、弹广告、改浏览器主页，或者早就停止更新、留着有安全风险 | 2345 全家桶、鲁大师、驱动精灵、驱动人生、快压、Flash 中心、Flash Player、hao123、百度卫士 / 杀毒 / 浏览器、猎豹、小鸟壁纸、各种浏览器工具条、Silverlight、QuickTime…… |
| **按需保留**（橙色） | 本身没问题，但推广、弹窗比较多；电脑里留一个安全软件就够了 | 360 全家桶、腾讯电脑管家、金山毒霸、McAfee WebAdvisor |

完整清单在 `junk_checker.py` 开头的 `RULES` 里，每一条都写了理由。

## 怎么用

只需要 Python 3.8 或更新的版本，不用装任何第三方库。

1. 双击 `junk_checker.py`，它会自动扫描
2. 红色、橙色的就是可疑的软件，点一下能看到原因
3. 想卸载：点「卸载…」，会打开这个软件**自己的**卸载程序（会先问你确认）；也可以点「去系统设置卸载」
4. 开机启动项：切到「开机启动项」标签页，点「去系统设置关掉开机启动」
5. 卸载完点「重新扫描」，看看是不是清理干净了

取消勾选「只看可疑的」可以看到全部软件，搜索框能按名称、发布者查找。

## 小提示

- 卸载时留意一下「再想想」「保留」之类的按钮，有些软件会用这种办法挽留你。
- 本工具只读取信息，**不会自己删除任何东西**。卸载都交给软件自己的卸载程序或者 Windows 设置来做。
- 它只认识清单里的常见软件，**没被标出来不代表一定安全**。怀疑中毒的话，请用杀毒软件（比如 Windows 自带的 Microsoft Defender）全盘扫描。

## 自己加规则

在 `junk_checker.py` 的 `RULES` 里照着格式加一行：

```python
Rule(JUNK, "显示的名字", ("关键词1", "关键词2"), "为什么建议卸载"),
```

关键词会在软件名称、发布者和开机启动命令里查找，不分大小写。只是弹窗多、但有人需要的软件，把 `JUNK` 换成 `OPTIONAL`。

## 运行测试

```bash
python -m unittest -v
```

在 Windows 上还会真的去读注册表：测试时临时写入几条测试用的登记，测完马上删掉。
