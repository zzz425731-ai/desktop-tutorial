# 📋 剪贴板历史

一个轻巧的小工具：自动记下你最近复制的 **8 条**文字，第 9 条进来时最旧的那条会自动删掉。支持搜索，双击就能复制回去。

![剪贴板历史截图：搜索 git 时的样子](screenshot.png)

## 功能

- **自动记录**：在任何程序里复制文字，都会出现在列表最上面
- **只留最近 8 条**：超过 8 条，最旧的自动删除
- **搜索**：边输入边过滤，不区分大小写；多个关键词用空格隔开，要全部包含才算匹配；预览里会把关键词标黄
- **复制回去**：双击某条记录，或者选中后按回车，它就回到剪贴板了（还会挪到最前面）
- **不重复**：再次复制已有的内容，只会把它挪到最前面，不会多存一份
- **关掉也不丢**：历史保存在 `~/.clipboard_history.json`，下次打开还在
- **窗口置顶**：勾上后窗口一直浮在最上层，边看边用很方便

## 怎么运行

只需要 Python 3.8 或更新的版本，不用装任何第三方库。

```bash
python clipboard_history.py
```

| 系统 | 说明 |
| --- | --- |
| Windows | 从 [python.org](https://www.python.org/downloads/) 装的 Python 自带 tkinter。不想看到黑色命令行窗口，就用 `pythonw clipboard_history.py` 启动 |
| macOS | python.org 的安装包自带 tkinter；用 Homebrew 装的 Python 需要再执行 `brew install python-tk` |
| Linux | 需要先装 tkinter，比如 Ubuntu / Debian：`sudo apt install python3-tk` |

想开机自动运行？Windows 上按 `Win + R` 输入 `shell:startup`，把一个指向 `pythonw clipboard_history.py` 的快捷方式放进去就行。

## 快捷键

| 想做什么 | 按键 |
| --- | --- |
| 跳到搜索框 | `Ctrl + F`（macOS：`⌘ + F`） |
| 在搜索结果里上下挑选 | `↑` / `↓` |
| 复制选中的记录 | `回车` 或双击 |
| 删除选中的记录 | `Delete`（先点一下列表） |
| 清空搜索 | `Esc` |

预览区里也可以只选中一部分文字，再按 `Ctrl + C` 单独复制。

## 小提示

- 只记录文字，复制图片或文件会被忽略。
- 工具开着的时候才会记录（最小化没关系）。打开之前就已经在剪贴板里的内容不会被记进来。
- 历史文件是明文保存的（只有你自己的账户能读）。如果复制过密码之类的敏感内容，记得在列表里把它删掉。

## 运行测试

```bash
python -m unittest -v
```

没有图形界面的环境（比如服务器）会自动跳过界面相关的测试。
